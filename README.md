# Login Form

A clean, modern login form built with HTML, CSS and a touch of JavaScript.

This repository contains a single-page login form demo that demonstrates layout, styling and simple client-side validation.

![Login Form Screenshot](./Screenshot%202024-08-09%20193214.png)

## Features

- Simple, responsive login UI
- Styled purely with CSS (no frameworks)
- Small JavaScript for basic client-side validation
- Easy to customize and reuse in projects or tutorials

## Files

- `index.html` — the markup for the login form
- `style.css` — styling and responsive rules
- `Screenshot 2024-08-09 193214.png` — screenshot used above
- `digital-art-isolated-house (1).jpg` — background / illustration asset (optional)

## How to use

1. Clone or download this repository

   git clone https://github.com/BinaryVortex/Login-Form-102.git

2. Open `index.html` in your browser (double-click or drag into a browser window).

Or run a simple HTTP server from the project folder (recommended for testing local files):

- Python 3: `python -m http.server 8000`
- Node.js: `npx http-server`

Then visit `http://localhost:8000`.

## Customize

- Edit `style.css` to tweak colors, spacing, and fonts.
- Modify `index.html` to add/remove fields or change markup.
- Replace the screenshot and background images with your own assets.

## Notes

- This demo includes only basic client-side validation and is not a secure authentication system. Do not use it as-is for production authentication.
